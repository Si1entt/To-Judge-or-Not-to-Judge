## 为什么选择这个组合

- 代码使用 MIT，方便他人研究、修改与集成。
- 数据使用 CC BY-NC 4.0，允许署名后的非商业复制、分享和改编；商业使用需另行获得相关权利人的许可。该限制针对使用目的，不等同于只允许高校使用。
- CC BY-NC 4.0 含非商业限制，因此数据不是通常意义上的完全开放许可；代码仍是开源软件。
- 自愿填写数据集使用登记表是社区请求，不是附加许可条件，也不要求先审批再下载。
